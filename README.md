# 🏗️ Multimodal Construction Intelligence Platform

A cutting-edge, AI-powered construction site intelligence platform featuring real-time vision monitoring, document intelligence, IoT sensor analytics, safety monitoring, and interactive project management dashboards.

---

## 🚀 Features

- **AI Vision Monitoring** — Real-time camera feeds with AI-powered defect detection, worker tracking, and progress analysis
- **Document Intelligence** — Smart parsing and analysis of blueprints, contracts, BIM models, and RFIs
- **IoT Sensor Analytics** — Live environmental monitoring (temperature, humidity, structural load, vibration, air quality)
- **Safety Monitoring** — Automated PPE compliance detection and incident reporting
- **Resource Management** — Equipment tracking, material inventory, and workforce allocation
- **Project Dashboard** — Interactive Chart.js visualizations for timeline, budget, and KPI tracking
- **Weather Intelligence** — Real-time weather impact assessment and construction forecasting
- **Risk Assessment** — AI-driven risk scoring and predictive analytics

## 🖥️ Getting Started

Since this is a pure frontend application, no build step is required.

### Option 1 — Open Directly
Simply open `index.html` in any modern browser.

### Option 2 — Local Server (recommended)
```bash
# Using Python
python -m http.server 8000

# Using Node.js / npx
npx serve .
```
Then navigate to `http://localhost:8000`.

## 📊 Dashboard Modules

1. **Overview** — Project health KPIs, budget burn rate, active alerts
